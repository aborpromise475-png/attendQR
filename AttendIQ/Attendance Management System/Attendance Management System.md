# 🎯 MAIN GOAL OF THE SYSTEM

The system should:

✅ identify students  
✅ record attendance  
✅ save data  
✅ allow lecturers to monitor attendance

That’s all for now.

# 👥 WHO WILL USE THE SYSTEM?

There are mainly 2 users.

## 👨‍🏫 Lecturer

The lecturer:

- logs in
- creates attendance session
- generates QR code
- views reports


## 👨‍🎓 Student

The student:

- logs in
- scans QR code
- marks attendance
- views attendance history

# 🔄 BASIC SYSTEM FLOW

```
Lecturer creates QR        ↓Student scans QR        ↓System verifies scan        ↓Attendance saved
```

That’s the ENTIRE idea simplified 🔥
